# Créditos

## Iconos de la barra lateral

Iconos de [The Noun Project](https://thenounproject.com) (buscados con filtro
*public domain* / CC0), recolorizados para el tema oscuro.

| uso | id Noun Project | archivo |
|-----|-----------------|---------|
| Sala | 7547948 | `app/icons/room.png` |
| Ocupantes | 1064877 | `app/icons/occupants.png` |
| Acciones | 100441 | `app/icons/actions.png` |
| Salir | 6733782 | `app/icons/leave.png` |
| Añadir | 2321848 | `app/icons/add.png` |

Los iconos del composer (adjuntar, emoji, micrófono, enviar, papelera, candado)
y del sidebar (perfil, acerca, sonido, vibración) son vectoriales de contorno,
dibujados en `addon/xat_xmpp/ui/icon_button.gd` (sin assets binarios).

Si algún icono resultara ser CC BY (no dominio público), hay que agregar el
nombre del autor/a junto al id. Los PNG se importan con Godot; la caché
`.import/` no se versiona (la regenera el editor al exportar).
