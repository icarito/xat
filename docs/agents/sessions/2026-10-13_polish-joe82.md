## 0.1.23 — plataforma Linux robusta (el release usa x11, no frt)
- **Descubrimiento:** el template Linux del release de xat es **platform=x11** (stock),
  que reporta `OS.get_name()=="X11"`; el build de dev usa frt ("Unix"/"Linux" tras el
  parche). Por eso el fix de frt (0.1.22) **no cubre al binario liberado** en Linux.
- **Fix en la app:** helper `addon/xat_xmpp/xmpp/platform.gd` (`is_linux()` acepta
  Linux/X11/Unix; `is_mac/is_windows/is_android/is_ios/is_mobile/is_desktop`) usado por
  `updater`, `credentials`, `camera`, `clipboard_image` y `file_picker`. Así el updater
  (auto-reemplazo) y las features de escritorio funcionan en el release Linux.
- Tests: `platform_test` (nuevo, ok=15); `updater_test` +2 (X11/Unix → asset linux); suite 80/80 OK.
